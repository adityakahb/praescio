About print support

How the Praescio plugin handles printed pages.

When a user prints a page that contains a Praescio autocomplete widget, the plugin automatically hides its suggestion panel and live region via @media print CSS rules. The underlying <input> element is preserved exactly as-is, so any typed or selected value will appear in the printed output. This means forms remain legible and useful when printed.

The .praescio__panel and .praescio__live elements receive display: none !important in print media — no configuration needed. Form input values are preserved and will appear in the printed page.

Implementation notes

How to add print support to pages using Praescio.

Required CSS

Add the following to your stylesheet (or the Praescio CSS already includes this):

@media print {
  /* Hide the dropdown panel and live region */
  .praescio__panel,
  .praescio__live {
    display: none !important;
  }

  /* Optionally hide navigation chrome */
  nav, .theme-toggle {
    display: none;
  }
}

No JavaScript needed

The print behaviour is handled entirely through CSS. No extra JavaScript is required. The input element retains its value attribute, which browsers render in print mode. If your form needs to capture the selected value for printing, assign it to a visible <output> or <span> element via the onSelect callback.

Utility classes for print

/* Hide on screen, show only in print */
.print-only { display: none; }

@media print {
  .print-only { display: block !important; }
  .no-print { display: none !important; }
}
