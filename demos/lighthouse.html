ESM import pattern

How to load Praescio as an ES module for optimal performance.

<!-- 1. Preload the module for faster startup -->
<link rel="modulepreload" href="./praescio.esm.js" />

<!-- 2. Import and initialise using type="module" -->
<script type="module">
  import { Praescio } from './praescio.esm.js';

  const ac = new Praescio('#my-input', {
    source: ['Austria', 'Belgium', 'Croatia'],
    maxItems: 8,
    onSelect: (item) => console.log(item.label),
  });
</script>

Using type="module" defers execution automatically — no defer attribute needed. The browser also handles module deduplication across imports.

Performance tips

Techniques used on this page to maximise Lighthouse scores.

  • M
    Module preload
    <link rel="modulepreload"> tells the browser to fetch and parse the ESM bundle during the HTML parse phase, before any script execution begins. This shaves tens of milliseconds off Time to Interactive.
  • C
    Non-blocking CSS load
    The plugin stylesheet uses the onload swap trick (rel="preload" as="style" switching to rel="stylesheet" on load) to prevent render-blocking. A <noscript> fallback ensures styles load without JavaScript.
  • I
    Inlined critical CSS
    CSS custom properties, base layout styles, and the Praescio panel dimensions are inlined in a <style> tag in <head>. This prevents Cumulative Layout Shift (CLS) by reserving space for the panel before the external stylesheet arrives.
  • A
    Accessibility first
    Single <h1>, proper landmark regions (header, main, footer, nav), visible focus styles, WCAG AA colour contrast, aria-live for dynamic updates, and a skip navigation link all contribute to a perfect accessibility score.
  • S
    SEO signals
    Descriptive <title>, meta description, canonical link, proper heading hierarchy, lang attribute on <html>, and meta name="robots" all improve crawlability and indexability.
  • B
    Best practices
    No deprecated APIs, no inline event handlers (CSP-friendly), valid HTML5, relative or HTTPS-only URLs, and explicit width/height on images prevent layout shifts and audit failures.
